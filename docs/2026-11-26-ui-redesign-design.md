# 5ch 中文论坛风 UI · A 方向（精致极简）重做设计

- 日期：2026-11-26
- 状态：已确认（2026-11-26，用户批准）
- 范围：本扩展全部 10 类页面 × 3 套主题，加设置弹窗

## 1. 为什么做

现版本 README 写的是参考 shadcn、Aceternity 等组件库，实际效果更像 Bootstrap 后台模板，部分页面布局还错位。用户在真实 5ch 页面上看过 A / B / C 三个方向的试样后，选了 **A 精致极简**（Linear / shadcn / Vercel 路线）。

丑的根因（11-26 实机截图确认）：
- 字体栈把 Microsoft YaHei 排在 Yu Gothic 前面，日文汉字全按简中字形渲染。
- 全站几乎都是 600–800 的粗体，没有层级。
- 每个 pill 都带边框，盒子套盒子。
- 圆角卡片加 4px 彩色左边条，四个角是歪的。

## 2. 目标 / 非目标 / 反目标

**目标**
- 10 类页面（首页、帖子、现代板块、旧版板块、subback、過去ログ、热榜、分类目录、全站板块导航、搜索）全部换成 A 的视觉语言，三套主题都要成立。
- 修掉第 5.6 节列出的错位和漏网广告，每条都修在根因上。
- 动效按参考站的思路做，但保持克制：只出现在交互反馈和首屏，阅读时页面不乱动。

**非目标**
- 不加新功能，不加新设置项。
- 不引入构建工具或框架，不打包 web font（只用 Windows 自带字体）。
- 不做 Shadow DOM 隔离（理由见 5.7）。
- 不处理 AA（ASCII art）专用字体；现版本本来就会把 AA 排乱，这次不变好也不变坏。

**反目标**（做到了也算失败）
- 盒子套盒子、彩色侧边条、彩虹色徽章。
- 同一屏里除标题外出现两种以上的粗细。
- 往下滚着读帖时内容还在动。
- 弄坏 5ch 原生的发帖表单（Shift_JIS 提交）或任何原生功能。
- 扩展加载后页面出现明显的布局跳动。

## 3. 约束

- MV3 content script，页面 DOM 不归我们管，只能在 5ch 原有结构上做样式和少量 DOM 注入。
- 内容脚本的 CSS 和页面 CSS 同处 author 层，现有规则大量依赖 `!important` 和高 specificity，新规则必须能压住它们。
- 部分旧页面没有 doctype，跑在 quirks mode。
- 本机可用字体：Segoe UI Variable、Yu Gothic（L/R/M/B）、Noto Sans SC（可变字重）、Microsoft YaHei、Consolas、MS PGothic；没有 Meiryo、Inter、Cascadia。
- 5ch 自带一个暗色模式开关（`#boardname` 里的「ダークモード」），不能和我们的主题打架。

## 4. 方案对比

| 方向 | 做法 | 取舍 |
|---|---|---|
| A 精致极简 ✅ | 白底细线，楼层之间只有分隔线不套卡片，左侧等宽行号栏放楼层号，作者名用老 2ch 名字栏绿 | 最耐看、最好读；"炫"的程度最低 |
| B 暗夜光效 | 黑底、点阵、极光，卡片边框跟随鼠标出多色光弧，楼主楼层有光束 | 最炫；长时间阅读偏累，浅色主题难成立 |
| C 新派论坛 | NGA 账本式楼层，左侧作者栏，大号楼层号 | 信息密度高；布局改动最大，偏复古 |

用户看完实机截图后选了 A。

## 5. 设计

### 5.1 设计令牌

三套主题共用同一套结构，只换颜色。主题 id 沿用现有的 `shadcn` / `nga` / `dark`，不改存储格式。

| 令牌 | 极简白 | 极简黑 | 羊皮纸 |
|---|---|---|---|
| canvas（页面底） | #FFFFFF | #0A0A0B | #F7F0DF |
| wash（浅底：输入框、轨道、悬停） | #F5F5F6 | #161618 | #EFE5CC |
| line（发丝线） | #E8E8EB | #26262A | #E2D4B2 |
| line-strong | #D4D4DA | #3A3A40 | #CDB98D |
| ink（标题） | #111113 | #EDEDEF | #2A1D0E |
| body（正文） | #2F2F35 | #C8C8CE | #3D2E1C |
| mute（次要信息） | #80808A | #7C7C85 | #8A7458 |
| faint（楼层号） | #B4B4BC | #55555C | #B9A684 |
| green（名字栏绿，唯一强调色） | #11823B | #3FB96A | #2E6B34 |
| heat（热度数字） | #B4540A | #F0A44B | #A14A0B |

- 主按钮用 ink 实色，不用渐变。
- 阴影只留给浮层（引用预览、灯箱、悬浮按钮），其余元素一律不带阴影。
- 圆角：控件 8px，容器 10px，徽章 5px。

### 5.2 字体

| 角色 | 字体栈 | 用在哪 |
|---|---|---|
| UI | "Segoe UI Variable Text", "Segoe UI", "Noto Sans SC", "Microsoft YaHei UI", sans-serif | 插件自己的中文标签 |
| 正文 | "Segoe UI Variable Text", "Segoe UI", "Yu Gothic", YuGothic, "Hiragino Sans", "Noto Sans JP", sans-serif；字重 500 | 帖子正文、标题、作者名等日文内容 |
| 数据 | Consolas, ui-monospace（tabular-nums） | 楼层号、ID、时间、计数 |

- Yu Gothic Regular 在 Windows 上太细，所以正文用 500，实际走的是 Medium。
- 字号：帖子标题 28/700，页面标题 22–24/700，列表标题 16–17/700，正文 15.5/1.9，UI 13/500，元信息 12。

### 5.3 组件语言

- **顶栏** 56px：canvas 86% 加模糊，底部一条发丝线。品牌位是 ink 方块「5ch」加「社区」。导航是纯文字：默认 mute，当前页 ink，下方 2px 下划线。搜索框是 wash 底，带 `/` 快捷键提示。主题切换是 wash 轨道加白色滑块。
- **按钮**分三级：primary（ink 实色）、secondary（发丝线描边）、ghost（无边框，悬停变 wash 底）。高 32px（小号 28px），按下缩放到 0.97。
- **标签页**：下划线式，2px 指示条滑动，沿用现有的 `attachSlidingIndicator`。
- **徽章**：楼主是绿色实底小标；热是 heat 色字配浅底；sage 是 mute。板块名直接用绿色文字，不加框。计数只用等宽数字，不加框。
- **容器**：能用列表加发丝线的地方就不用卡片。必须分组时，用 1px line、10px 圆角、无阴影。
- **浮层**：引用预览、灯箱、悬浮按钮、toast 用 canvas 底、发丝线、阴影 md；toast 用 ink 底。

### 5.4 各页面

1. **帖子页**
   - 阅读栏最宽 880px。
   - 面包屑做成一行小字，不加框。
   - 标题 28px，下面是下划线标签工具栏（全部 / 只看楼主 / 亮评 / 带图）、筛选框和 primary「快速回帖」。
   - 亮评区是 wash 小块。原生的分页导航和阅读工具统一成小号 secondary 按钮。
   - 每层楼：左侧 64px 行号栏放楼层号（等宽 faint，楼主那层用绿色加粗）。右侧依次是：
     - 作者行：28px 圆角方头像、绿色名字、楼主徽章、等宽 ID 加本帖发言数、时间。
     - 引用行：2px 左线，加一行 mute 摘要。
     - 正文。
     - 底栏：回复数（绿）、回复楼层 chip、楼中楼开关，右侧是 ghost 的「回复 / 复制」。
   - 楼中楼展开后是 wash 面板。回帖框去掉外框，上方一条发丝线。
2. **首页**
   - 主栏加 248px 侧栏。
   - 帖子是列表加发丝线：标题 17/700，摘要两行 mute，元信息行依次是回复数、板块（绿字）、热度（heat）、小号 secondary 的「フォローする」。
   - 侧栏是纯文字板块列表加分组小标题。公告条用 wash 底。
3. **现代板块页**（`/test/read.cgi/<board>`）
   - 标题区是面包屑、24px 标题和元信息，不加左色条。版规做成 wash 折叠条。
   - 工具行（搜索、排序、按钮）统一 secondary。「发表新帖」用 primary。
   - 帖子表：外层发丝线容器；表头 wash 小字；行间发丝线，不加斑马纹。
   - 列：排名用等宽数字，前三名用 heat 色字，不再用红、橙、黄色块；回复数等宽右对齐，热帖用 heat 色；新着绿字；日期 mute 等宽；勢い用 heat 色等宽。
4. **旧版板块 / subback / 過去ログ**（插件自建外壳）
   - 标题区是 h1、元信息和操作按钮，不加卡片和左色条。
   - 控制行：搜索框加分段排序。
   - 列表行：回复数（等宽右对齐，热帖用 heat 色）、标题、`#序号`（faint）。
   - 過去ログ用两栏：列表加日期侧栏。
5. **热榜页**（`/test/read.cgi/`）
   - 标题、排行切换（下划线标签）和工具收进同一个标题区。原生链接行做成安静的次级导航。
   - 帖子用网格（auto-fill，最小 320px）。每格不加框，顶部一条发丝线，左侧等宽排名（前三名 heat 色），下面是标题和「板块 · レス · 勢い」。
6. **分类目录 / 全站板块导航**
   - 改用 CSS 多栏（masonry 效果）加 `break-inside: avoid`，不再是 grid 等高。
   - 每个分类：标题加板块数，板块链接用无边框的 wash chip。
7. **搜索页**
   - 容器和搜索框左右对齐，去掉空白广告位。
   - 结果是列表加发丝线：标题 16/700，回复数徽章，元信息里板块用绿字、时间 mute、速度 heat。
8. **设置弹窗**（popup）：换成 A 的浅色令牌，结构不变。

### 5.5 动效

参考 Motion Primitives、Animate UI 和 Magic UI 的思路，只做下面这些：

- 标签页下划线滑动：280ms，spring ease（已有 JS，换样式即可）。
- 按钮按下缩放到 0.97；链接和按钮颜色过渡 150ms。
- 复制按钮的图标从 copy 变成 check，同时变绿（已有）。
- 引用预览浮层淡入，并从 0.98 缩放到 1（已有，调参数）。
- 跳到指定楼层时，那层的 wash 底高亮 1.2s 后淡出，取代现在的描边光圈。
- 首屏淡入：列表和楼层只在首屏出现时淡入并上移 6px，时长不超过 240ms，前 8 项每项错开 30ms。滚动阅读时不再有任何动画。
- 切换主题时用 View Transitions 做整页 cross-fade（`document.startViewTransition`，不支持的浏览器直接切）。
- 以上全部遵守 `prefers-reduced-motion`。

### 5.6 错位与漏网广告（根因 → 修法）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 過去ログ页被拆成三栏，标题卡缩成空白竖条 | 原站 CSS 给 `main` 设了 grid，插件外壳也是 `<main>` | 外壳上重置 `display`、`grid-*`、`background`、`width`、`margin` |
| 2 | 搜索页结果列表比搜索框左右各宽 15px | Bootstrap `.row` 的 -15px margin | 在搜索页规则里抵消该 margin，统一容器宽度 |
| 3 | 热榜页 h1 只有 49px 宽，原生链接没样式，排序按钮挤在小框里 | 插件只给原站 flex 结构里的部分元素加了样式 | 重排标题区（5.4 第 5 条） |
| 4 | 旧版板块 / subback / 目录页顶栏搜索框上偏 8px，控件字体变成 Arial | quirks mode 的浏览器默认样式：`form` 带 1em 下边距，表单控件不继承字体 | 插件注入的 form 设 `margin: 0`，所有注入控件设 `font: inherit` |
| 5 | 分类页卡片等高，留大片空白 | grid 行高被最高的卡片撑开 | 改用多栏布局 |
| 6 | 首页 UPLIFT 横幅、帖子页 gzo.ai 文字广告、搜索页空广告位 | 广告选择器没覆盖到 | 隐藏 `a[href*="uplift.5ch"]` 所在块、`.navmenu .uploadlink`、搜索页广告容器（实现时确认选择器） |
| 7 | 首页「フォローする」没有靠右 | `margin-left: auto` 写在按钮上，但按钮外面还包了一层 | 改到外层容器上 |
| 8 | 主题滑块偶尔对不准 | 指示条的宽度是在字体加载完之前量的 | `document.fonts.ready` 之后再同步一次 |

### 5.7 样式隔离

11-26 用 CDP 查过顶栏在旧页面上的计算样式。泄漏只有两类：quirks mode 的浏览器默认样式（form 边距、控件字体），以及几条标签选择器（`main`、`a:link`）。对注入元素做针对性重置就够了，不上 Shadow DOM。

Shadow DOM 的代价是：样式必须单独加载进 shadow root（需要 `web_accessible_resources` 加异步加载，或者把 CSS 写成 JS 字符串）。如果实现时在 10 类页面上发现更多泄漏，再回来评估。

## 6. 验收

- 用 Playwright 缓存的 Chromium（品牌版 Chrome 158 已不认 `--load-extension`）加载解压扩展，截真实页面。
- 10 类页面 × 3 主题，1440 宽各截一张；帖子页、首页、现代板块页再补 1024 和 390 宽。
- 每页自动检查两项：没有横向溢出；主要容器的左右边缘对齐。
- 手动过一遍交互：筛选标签、引用悬停预览、复制、灯箱、主题切换、「原版」开关、`/` 快捷键、回帖框。

## 8. 第二轮修改（2026-11-26，用户看过 v3.1 后的反馈）

**反馈**：极简白整体可以，但对比度不明显，看久了眼睛累，区分度也差；全站板块分类目录太原始，和首页格格不入。

**取舍**：实机对比了三版——V1 加深（保持无卡片）、V2 白纸灰底、V3 楼层框。用户选了 **V1**，分类目录的新布局也确认了。

  - 板块用自动填充网格排成圆点列表，样式和首页侧栏一致。
  - 工具行右侧显示「N 个分区 · M 个板块」。
